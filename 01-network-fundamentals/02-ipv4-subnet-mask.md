## 1. IPv4 주소의 기본 구조

- IPv4 주소 형식: `X.X.X.X`

- 10진수 네 개로 표현하며, 각 자리는 8bit입니다.

- 전체 길이: `8bit × 4 = 32bit`

- 주소는 **Network 자리(동)**와 **Host 자리(번지)**로 구분됩니다.

## 2. 8bit와 10진수 변환

8bit의 최솟값과 최댓값:

- **최솟값:** `00000000` = 0

- **최댓값:** `11111111` = 255

각 비트의 값(왼쪽부터):

- 2⁷ = 128

- 2⁶ = 64

- 2⁵ = 32

- 2⁴ = 16

- 2³ = 8

- 2² = 4

- 2¹ = 2

- 2⁰ = 1

예시 변환:

- `11000000` = 192

- `11100000` = 224

- `11110000` = 240

- `11111000` = 248

## 3. Classful Address와 서브넷 마스크

서브넷 마스크에서 **1은 Network 자리**, **0은 Host 자리**를 나타냅니다.

### A Class

- 첫 번째 옥텟 범위: 1–126

- 기본 서브넷 마스크: `255.0.0.0`

- 2진수 마스크: `11111111.00000000.00000000.00000000`

- CIDR: `/8`

### B Class

- 첫 번째 옥텟 범위: 128–191

- 기본 서브넷 마스크: `255.255.0.0`

- 2진수 마스크: `11111111.11111111.00000000.00000000`

- CIDR: `/16`

### C Class

- 첫 번째 옥텟 범위: 192–223

- 기본 서브넷 마스크: `255.255.255.0`

- 2진수 마스크: `11111111.11111111.11111111.00000000`

- CIDR: `/24`

## 4. 네트워크 주소 · 브로드캐스트 주소 · 사용 가능 주소

- **Network 주소**: Host 부분의 비트가 모두 0인 주소이며, 특정 PC에 할당하지 않습니다.

- **Broadcast 주소**: Host 부분의 비트가 모두 1인 주소이며, 특정 PC에 할당하지 않습니다.

- **사용 가능 주소 수**: 일반적인 IPv4 서브넷 계산에서는 전체 주소 수에서 네트워크 주소와 브로드캐스트 주소를 제외합니다.

### 예제 A — A Class

- IP 주소: `126.255.255.1`

- 서브넷 마스크: `255.0.0.0` (`/8`)

- Network 주소: `126.0.0.0`

- Broadcast 주소: `126.255.255.255`

- 사용 가능 주소 범위: `126.0.0.1 – 126.255.255.254`

- 사용 가능 주소 수: `2²⁴ − 2 = 16,777,214`

### 예제 B — B Class

- IP 주소: `191.255.255.1`

- 서브넷 마스크: `255.255.0.0` (`/16`)

- Network 주소: `191.255.0.0`

- Broadcast 주소: `191.255.255.255`

- 사용 가능 주소 범위: `191.255.0.1 – 191.255.255.254`

- 사용 가능 주소 수: `2¹⁶ − 2 = 65,534`

### 예제 C — C Class

- IP 주소: `223.255.255.1`

- 서브넷 마스크: `255.255.255.0` (`/24`)

- Network 주소: `223.255.255.0`

- Broadcast 주소: `223.255.255.255`

- 사용 가능 주소 범위: `223.255.255.1 – 223.255.255.254`

- 사용 가능 주소 수: `2⁸ − 2 = 254`

## 5. 네트워크 주소가 같은 경우와 다른 경우

### Network 주소가 같은 경우

- PC1 ↔ PC2

- PC1 — Hub — PC2

- PC1 — Switch — PC2

- 원문 메모에서는 Hub와 Switch를 **L2 장비**로 표시합니다.

### Network 주소가 다른 경우

- PC1 — Router — PC2

- 원문 메모에서는 Router를 **L3 장비**로 표시합니다.

## 핵심 요약

- IPv4는 **32bit**, 즉 8bit씩 네 구간으로 구성됩니다.

- 8bit의 값 범위는 **0–255**입니다.

- 서브넷 마스크에서 **1 = Network**, **0 = Host**입니다.

- A/B/C 클래스의 기본 프리픽스는 각각 **/8, /16, /24**입니다.

- 일반적인 서브넷에서 사용 가능 주소 수는 **2^(Host 비트 수) − 2**로 계산합니다.

- 서로 다른 네트워크 사이의 통신에는 일반적으로 Router와 같은 L3 장비가 필요합니다.

## 원문 표기 확인

B Class 예제의 원문에는 Network 주소가 `191.0.0.0`, 사용 가능 범위가 `191.255.(0.1–255.254)`로 적혀 있습니다. C Class 예제의 원문에는 Network 주소가 `223.0.0.0`로 적혀 있습니다. 위 정리에서는 각 예제 IP와 서브넷 마스크에 맞춰 주소를 정리했습니다.
